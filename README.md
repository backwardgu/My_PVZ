项目名称：
C++实现《植物大战僵尸》仿制版


项目简介：
基于C++和EasyX图形库，独立实现《植物大战僵尸》第一关的完整玩法。重点优化了资源管理和性能开销，体现了对C++内存管理和游戏循环设计的理解。


核心功能：
完整实现阳光系统（自动生成+点击收集）
实现两种植物和一种僵尸的设计
实现碰撞检测、子弹与僵尸交互、资源管理等设置
实现关卡流程控制（出怪波次、胜利/失败判定）


技术亮点：
1. 对象池优化
参考教程中反复调用load_image()造成内存碎片和性能开销，自主设计并实现对象池结构管理频繁创建销毁的游戏对象（如子弹、僵尸），减少动态内存分配，提升运行效率。

2. 资源管理重构
将对象池的优化思路扩展到植物系统和子弹系统，对原有代码进行系统性重构，形成统一的资源管理模块。

3. 模块化设计
将游戏核心模块拆分为：阳光系统、植物系统、僵尸系统、碰撞检测系统、场景管理系统等，便于后续的扩展和开发。
